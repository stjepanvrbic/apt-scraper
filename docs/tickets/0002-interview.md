## Outcome

The agent interviews the user before the first search and keeps criteria, preferences, listing sites and availability that the user can change by talking to it.

## Acceptance

- [ ] A first chat runs the interview and stores criteria, preferences, listing sites and availability.
- [ ] Telling the agent a new criterion changes the stored criteria.
